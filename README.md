# 英语四六级复习 App

一个**完全离线、双击即开**的英语四六级（CET-4 / CET-6）单词与题库复习工具。无需联网、无需安装，所有数据保存在你自己的浏览器里。

---

## ✨ 功能特性

- **双模式**：四级（CET-4）/ 六级（CET-6）词库与题库完全隔离，一键切换。
- **背单词（闯关模式）**：
  - 四选一作答，切换单词时**自动朗读**发音。
  - 答对显示绿色 ✓、答错显示红色 ✗ 动效。
  - 每背一个词计数 +1；背完当日目标自动完成并弹出提示。
- **每日计划**：自由设定「每日新词数」（1–200），首页随机展示中英文双语励志名言并高亮词库命中词。
- **断点续背**：退出背单词界面自动存档，下次进入从上次进度继续。
- **错题本**：
  - 答错的单词自动入册，记录错误次数。
  - **开始纠错**：按错词顺序逐题重做，答对即移出错本。
  - **错题重做**：从历史错本随机抽取题目巩固记忆。
- **多词库 / 多题库管理**：上传、下载、切换词库与题库，并保留学习进度。
- **离线导入**：支持 `Word(.docx)`、`Excel(.xlsx)`、`PDF(.pdf)`、`CSV(.csv)` 四种格式的单词/题目导入。
- **数据统计**：连击天数、累计学习量、掌握度分布。
- **交互体验**：
  - 浅色 / 深色一键切换。
  - 跟随式圆环光标（深浅主题自适应）。
  - 按钮 hover 抬升 + 点击水波纹动效。
  - 实时合成音效（点击 / 答对 / 答错 / 完成），可一键静音。
  - 背单词界面**全屏模式**，页面干净清爽。
- **内置默认词库**：CET-4 约 4400 词、CET-6 约 5500 词（开箱即用）。

## 📥 数据导入格式

### 词库（Word / Excel / PDF / CSV）
每行一个单词，建议包含三列：`单词, 音标, 释义`

```
word,phonetic,meaning
abandon,/əˈbændən/,v. 抛弃；放弃
ability,/əˈbɪləti/,n. 能力；才能
```

- 表头行（`word`/`phonetic`/`meaning`）会被自动跳过。
- PDF 为「尽力解析」，复杂排版的识别率可能较低，推荐用 Word/Excel/CSV。

### 题库（Word / Excel / PDF / CSV）
每行一道题，建议包含：`题干, 选项A, 选项B, 选项C, 选项D, 正确答案(字母)`

```
question,A,B,C,D,answer
"下列说法正确的是？","A对","B对","C对","D对",C
```

导入后自动切换为当前题库。

## ⌨️ 交互说明

- **切换单词自动发音**：进入背单词后无需手动点击，系统自动朗读当前单词。
- **全屏**：背单词界面右上角图标进入全屏，按 `Esc` 退出。
- **音效开关**：顶栏小喇叭图标，可随时静音 / 开启。
- **主题切换**：顶栏图标在浅色 / 深色之间切换，偏好已保存。
- **进度保存**：所有学习记录实时写入浏览器本地，关闭页面不丢失。

## 🔒 隐私与离线

- **完全离线**：页面不发起任何网络请求，适合无网环境学习。
- **数据本地存储**：所有学习进度仅保存在你当前浏览器，不上传任何服务器。
