# 英语四六级复习 App

一个**完全离线、双击即开**的英语四六级（CET-4 / CET-6）单词与题库复习工具。无需联网、无需服务器、无需安装，所有数据保存在浏览器本地。

> 纯前端单页应用（SPA）：原生 HTML + CSS + JavaScript，**零框架、零 CDN、零外部请求**，断网也能用。

---

## ✨ 功能特性

- **双模式**：四级（CET-4）/ 六级（CET-6）词库与题库完全隔离，一键切换。
- **背单词（闯关模式）**：
  - 四选一作答，切换单词时**自动朗读**发音（Web Speech API）。
  - 答对显示绿色 ✓、答错显示红色 ✗ 动效。
  - 每背一个词计数 +1，从 `0/x` 开始；背完当日目标自动完成并弹出提示。
- **每日计划**：自由设定「每日新词数」（1–200），首页随机展示中英文双语励志名言并高亮词库命中词。
- **断点续背**：退出背单词界面自动存档，下次进入从上次进度继续。
- **错题本**（替代原「复习」设定）：
  - 答错的单词自动入册，记录错误次数。
  - **开始纠错**：按错词顺序逐题重做，答对即移出错本。
  - **错题重做**：从历史错本随机抽取 `N` 个，`N = 100 + 50 × ⌊累计背词数 / 1000⌋`（错题不足 100 按实际数量）。
- **多词库 / 多题库管理**：上传、下载默认词库、切换词库并**保留学习进度**；题库同构。
- **离线导入**：支持 `Word(.docx)`、`Excel(.xlsx)`、`PDF(.pdf)`、`CSV(.csv)` 四种格式的单词/题目导入。
- **数据统计**：连击天数、累计学习量、掌握度分布（纯 SVG 图表）。
- **交互体验**：
  - 浅色 / 深色一键切换（米白·天蓝·青绿配色）。
  - JS 跟随式**圆环光标**（带惯性平滑，深浅主题自适应）。
  - 按钮 hover 抬升 + 点击水波纹动效。
  - **Web Audio 实时合成音效**（点击 / 答对 / 答错 / 完成），离线零文件，可一键静音。
  - 背单词界面**全屏模式**，页面干净清爽。
- **内置默认词库**：CET-4 约 4400 词、CET-6 约 5500 词（开箱即用）。

## 📥 数据导入格式

### 词库（Word / Excel / PDF / CSV）
每行一个单词，建议包含三列：`单词, 音标, 释义`
（CSV 示例）

```
word,phonetic,meaning
abandon,/əˈbændən/,v. 抛弃；放弃
ability,/əˈbɪləti/,n. 能力；才能
```

- 表头行（`word`/`phonetic`/`meaning`）会被自动跳过。
- PDF 为「尽力解析」，复杂排版的识别率可能较低，推荐用 Word/Excel/CSV。

### 题库（Word / Excel / PDF / CSV）
每行一道题，建议包含：`题干, 选项A, 选项B, 选项C, 选项D, 正确答案(字母)`
（CSV 示例）

```
question,A,B,C,D,answer
"下列说法正确的是？","A对","B对","C对","D对",C
```

导入后自动切换为当前题库。

## ⌨️ 交互说明

- **切换单词自动发音**：进入背单词后无需手动点击，系统自动朗读当前单词。

## 🛠 技术栈

- 原生 HTML5 + CSS3 + ES6 JavaScript（UMD 模块化拆分）
- 状态与逻辑：`logic.js`（多词库 / 多题库 / SRS / 错题本模型）
- 离线解析：`parsers.js`（浏览器原生 `DecompressionStream` 解包 docx/xlsx，PDF 尽力解析）
- 界面胶水层：`app.js`（视图渲染、动效、音效、光标、全屏）
- 数据持久化：`localStorage`
- 测试：`tests/`（Node 运行，71 项用例全部通过）

## 🔄 部署与更新（GitHub Pages）

本项目已通过 GitHub Pages 上线。如需重新部署或更新：

1. 在 GitHub 生成 Personal Access Token（classic，`repo` 权限）。
2. 本地提交改动：
   ```bash
   git add -A
   git commit -m "更新说明"
   ```
3. 配置远程并推送（token 仅用于本次推送，用完即删）：
   ```bash
   git remote set-url origin https://<TOKEN>@github.com/ZIYANGDING666/cet4-6-review-app.git
   git push
   ```
4. 推送后抹去远程地址中的 token：
   ```bash
   git remote set-url origin https://github.com/ZIYANGDING666/cet4-6-review-app.git
   ```
5. 登录 GitHub → Settings → Developer settings → 撤销该 Token。

> GitHub Pages 会在推送后自动重新构建，通常 1–2 分钟生效。
